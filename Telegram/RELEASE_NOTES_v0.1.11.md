# mokaGram v0.1.11

Windows Release. Сборка основана на Telegram Desktop 7.4.4 и включает изменения mokaGram после v0.1.10.

## Производительность и стабильность

- Добавлена полноценная оптимизированная Windows Release-сборка с `/O2` вместо Debug-сборки с `/Od` и `/RTC1`.
- Ускорено создание галочек у сообщений: хранилище custom emoji переведено с линейного `flat_map` на хеш-таблицу. Это уменьшает задержки при загрузке больших историй.
- История восстанавливается небольшими порциями, проверка обычных сообщений и обход ответов сокращены.
- Плеер останавливает индикатор поиска и таймеры в фоне и на паузе.
- Анимация питомца и эффекты не продолжают тратить ресурсы в фоне.
- Исправлены падения при выходе из плеера, при ошибке открытия локальной базы и при обработке просроченных вызовов плагинов.

## Windows и сборка

- Исправлена Windows-сборка профиля, панели плеера, слоя информации, настроек бейджей и области Dynamic Island.
- В релизный комплект включается embed Python 3.12 для плагинов, без установки Python в систему.
- Исправлена отложенная загрузка `python312.dll`: имя DLL берётся из выбранного embed runtime, а не из системного интерпретатора.
- Исправлены ошибки MSVC с `/WX`, включая несовместимости Debug и Release-конфигураций.
- Обновлён набор Windows-зависимостей для Release-сборки.

## Плагины

- Python-плагины снова работают через стабильный Python 3.12 runtime.
- Улучшены кеши изменённых сообщений и отмена просроченных вызовов.
- Усилено безопасное восстановление резервной копии и обработка ошибок хоста плагинов.
- Плагины не блокируют запуск клиента при отсутствии runtime: движок отключается отдельно.

## Интерфейс и профиль

- Карточки профиля снова имеют отдельный контрастный фон на тёмных палитрах.
- Скругление карточек и внутренние отступы масштабируются вместе с интерфейсом.
- Исправлено обновление иконки в панели задач после смены иконки клиента.
- Восстановлена стандартная иконка и корректно отображается выбранная иконка в Windows.
- Кнопка участников растянута на шапку профиля и выровнена по центру.

## Музыка и SoundCloud

- Очередь плеера показывается вместо пустого состояния текста песни.
- Новые лайки SoundCloud добавляются блоком и сохраняют порядок аккаунта.
- Убраны затемнения по краям списка.
- Добавлены логи диагностики ответа при записи лайка.

## Проверка релиза

- Собран `Telegram.exe` для Windows x64 в конфигурации Release.
- Проверена таблица импортов: `python312.dll` находится в delay-load imports.
- В релизный архив не включаются `tdata`, логи и иные пользовательские данные.
