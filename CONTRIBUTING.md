
# Contributing

Thank you for considering contributing to Telegram Desktop.

Small changes that are easy to review are preferred. To help your contribution land quickly, please follow these simple steps:

1. Fork the repository and create a feature branch from `dev` or the branch relevant to your change.
2. Keep commits small and focused. Use clear commit messages.
3. Run the build and smoke-test the app locally if your change affects code.
4. Update documentation or add a short note in the PR description for user-visible changes.
5. If your change fixes a bug, include steps to reproduce in the issue or PR.

If you're not sure where to start, look for issues labelled `good first issue` or `help wanted`.

Thanks — we appreciate small, thoughtful improvements!
